快速开始

3 步接入，让 AI 拥有价格监控能力

1

安装 Chrome 扩展

在 Shopee 商品页点击扩展图标，一键添加监控，设置降价阈值。系统自动开始采集价格数据。

2

配置飞书推送

在扩展设置中粘贴飞书群 Webhook 地址。竞品降价时，系统自动推送预警卡片到群里。

3

接入 MCP

在你常用的 AI 客户端中添加 MCP 配置，即可用自然语言查询监控数据、管理监控任务。

// 在你的 MCP 客户端中添加以下配置
{
  "mcpServers": {
    "sentinel": {
      "command": "uvx",
      "args": ["sentinel-mcp-server"],
      "env": {
        "SENTINEL_API_BASE": "https://api.gf-yun.cn/api/v1",
        "SENTINEL_TOKEN": "你的 API Token"
      }
    }
  }
}

10 个 MCP Tools

覆盖查询、操作、洞察三大场景

查询 get_monitor_list

获取用户正在监控的商品列表。支持按站点和状态筛选。

我在盯哪些商品 SG 站有几个商品在监控 我的监控列表
查询 get_price_summary

获取价格摘要：当前价、基准价、最高/最低/均价、趋势方向。支持单个或批量。

竞品最近价格怎么样 有没有降价的竞品 近 2 天价格怎样
查询 get_price_history

获取时间序列价格数据，AI 可渲染为折线图或做趋势分析。

价格走势怎么样 画个价格折线图 近 7 天价格变化
查询 get_alerts

获取价格预警列表，查看系统推送过的所有降价预警。支持未读筛选。

有没有新的降价预警 最近哪些商品降价了 未读预警有几条
操作 add_monitor

添加新商品到监控列表。只需提供一个 Shopee 商品 URL。

帮我监控这个商品 把这个加到监控列表 盯一下这个竞品
操作 update_monitor_status

暂停或恢复某个监控项。灵活管理你的监控任务。

暂停 iPhone 那个监控 恢复 Samsung 的监控 把 AirPods 停掉
操作 mark_alert_read

将某条预警标记为已读，保持预警列表干净。

把这条预警标记已读 所有预警都标为已读 我已经看过了
洞察 get_crawl_health

检查后台采集引擎运行状态：采集次数、成功率、各站点运行情况。

采集系统正常吗 今天采集了多少次 各站点成功率怎样
洞察 get_monitor_overview

获取监控大盘总览：活跃数、今日采集/预警、站点分布、降价占比。

给我一个监控总览 大盘数据看看 监控情况怎样
洞察 search_my_products

在监控列表中按关键词搜索商品，匹配商品名或店铺名。

搜一下 AirPods Samsung 相关的有几个 那个卖耳机的店铺

常见问题

关于 MCP Server 的常见疑问

如何获取 API Token？

安装 Chrome 扩展后，在扩展设置页面可以看到你的 Token。或者通过 POST /auth/init 接口创建。

支持哪些 Shopee 站点？

目前支持 SG（新加坡）、MY（马来西亚）、TH（泰国）、VN（越南）四个站点。

数据采集频率是多少？

默认每 2 分钟采集一次，可在监控设置中自定义间隔。

MCP 和 Chrome 扩展是什么关系？

Chrome 扩展负责"一键加监控"和数据采集；MCP Server 让 AI 能查询和管理你的监控数据。两者共用同一个后端。
